Privacy Policy

ZCapitan Uploader. Last updated: October 28, 2026.

ZCapitan Uploader is a private tool used only by Frank Reyes, the owner of the ZCapitan YouTube channel, to upload and manage videos on his own YouTube channel through the YouTube Data API.

Information collected

The tool collects no data from anyone other than the channel owner. It does not collect, store or process information about viewers, subscribers or any other person.

How data is stored

The only credential used is the owner's own Google OAuth token. It is stored only on the owner's private machine and is used only to act on his own channel.

Sharing

No data is sold, shared or transferred to any third party.

YouTube API Services

ZCapitan Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access granted to the tool can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
